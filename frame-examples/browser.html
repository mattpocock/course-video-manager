Managing Services

Effect tracks the services a program needs in its type, so a missing one is a compile error rather than a crash at 3am.

Declaring a service

Effect.Service declares the tag, the implementation and the default Layer in one go. The string is the service's identity.

class FrameCaptureService extends Effect.Service<FrameCaptureService>()( "FrameCaptureService", { effect: Effect.gen(function* () { /* … */ }) } ) {}

Why it matters here

Anything that talks to the outside world — a browser, a speech API — goes behind one of these, so everything else can be tested without it.
